# Ricardo Silva | Portfolio

Personal portfolio focused on people management, process coordination, and operational improvement. Based in Guimarães, Portugal.

## Overview

The site is built with Next.js, Tailwind CSS, and a modern minimal UI. It includes sections for:

- Professional introduction and focus areas
- Experience and education
- People, process, and operations capabilities
- Selected digital projects
- About page and contact links

## Local setup

```bash
npm install
npm run dev
```
